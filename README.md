## 功能说明

-  添加一个骰子🎲
	-  点击右侧＋号
	-  填写骰子名称和骰子面数
	-  添加成功！
-  修改一个骰子🎲
	-  长按某个骰子
	-  在弹出页面中选择「编辑」
	-  填写新的骰子名称和骰子面数
	-  修改成功！
-  删除一个骰子🎲
	-  长按某个骰子
	-  在弹出页面中选择「删除」
	-  删除成功！
-  掷出骰子🎲
	-  点击「投掷」按钮，所有骰子都掷出去啦！
